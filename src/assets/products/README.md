# Product image slots

Product photography is kept separate from editorial food imagery. When a real Koko Market photo is supplied, place it in a product folder using these slots:

```text
products/
  koko-shito/
    main.jpg
    secondary.jpg
    detail.jpg
    serving.jpg
```

The current catalogue uses the supplied food photographs in `../images/`; each product's `image` is its main product photo and `gallery` holds the supported secondary/detail/serving sequence. Do not replace a missing product photograph with unrelated stock or generated packaging.
